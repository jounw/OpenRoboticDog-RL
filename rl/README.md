# OpenRoboticDog RL

The full documentation (policy status, hardware, wiring and power, setup, running in the sim and on the robot, training) is in the [main README](../README.md).

- `sim/`: MuJoCo model, training code and servo data sheet. See [`sim/learn/README.md`](sim/learn/README.md) and [`sim/sysid/SERVO_DATASHEET.md`](sim/sysid/SERVO_DATASHEET.md).
- `deploy/`: policy runner, web joystick, servo and IMU drivers, calibration files and trained policies.
- `docs/`: photo and demo GIFs used in the main README.
